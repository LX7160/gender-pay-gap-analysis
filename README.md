# Gender Pay Gap by Education Level and Race
This project used U.S. Census Bureau CPS ASEC data from 2020-2024 to analyze differences in median annual earnings among different genders, education levels, and racial groups.

## Work included
- Data visualizations on earnings and the female-to-male earnings ratios across different educational levels and racial groups.
- Hypothesis tests and regression model application.
- Analysis of differences in earnings across various demographic groups.

## Files
- Analysis report: GPG project.pdf 
- Code: GPG project.qmd

## Tools Used
R, ggplot2, dplyr, tidyr, and R Markdown.
